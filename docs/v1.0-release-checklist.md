# v1.0 Release Checklist

Infrastructure is frozen as of the Phase 7 milestone (commit `a102566`).
No new database redesigns, auth rewrites, storage refactors, or architecture
churn. From here on: additive migrations only.

## Schema v1 — frozen

Tables `rs_*` + storage buckets are declared v1. RLS, FKs, cleanup tooling
(`pnpm cleanup:e2e`), and idempotent seeding (`pnpm seed:e2e`) are verified.

- No renaming of tables/columns, no relationship changes.
- New fields arrive via additive migrations with backfill defaults.
- New tables get the same RLS + FK discipline as existing ones.
