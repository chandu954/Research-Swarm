Infrastructure is frozen as of the Phase 7 milestone (commit `a102566`).

churn. From here on: additive migrations only.

Tables `rs_*` + storage buckets are declared v1. RLS, FKs, cleanup tooling
(`pnpm cleanup:e2e`), and idempotent seeding (`pnpm seed:e2e`) are verified.
