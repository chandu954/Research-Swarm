Design Decisions

Why This Stack?

Each choice solves a specific engineering problem

LangGraph → Orchestration

Stateful multi-agent workflows with parallel execution, merge points, and observability.

FastAPI → Backend APIs

Async REST + SSE streaming with Pydantic validation and OpenAPI docs.

ChromaDB → RAG

Semantic search over PDF chunks with embeddings and reranking.

PostgreSQL → Persistence

Users, conversations, tasks — async SQLAlchemy with Alembic migrations.

Docker → Deployment

One-command startup for frontend, backend, database, and Ollama.

OpenRouter → 150+ Models

Provider abstraction — different models per agent, cloud or local.
